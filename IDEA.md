# DBH-WW1 Game Idea

## Название
**DBH-WW1** - 3D игра от первого лица

## Язык и движок
- **Язык:** Python
- **Движок:** Ursina Engine (https://ursinaengine.com)

## Концепция
Простая 3D игра с видом от первого лица, где игрок может перемещаться по карте, взаимодействуя с различными 3D объектами.

## Управление
- **WASD** - движение вперёд/назад/влево/вправо
- **Мышь** - изменение направления взгляда (поворот камеры)
- **SHIFT** - бег (увеличенная скорость движения)
- **C** - присесть (уменьшенная высота камеры)
- **Пробел** - прыжок

## Карта
- Размер: произвольный (определяется в JSON файле, напр. 64x64)
- Тип: сетка высот (heightmap)
- Покрытие: трава (grass), вода (water), песок (sand) и др.

### Формат карты (map.json)
```json
{
  "width": 64,
  "height": 64,
  "cellSize": 1.0,
  "heightmap": [[0, 1, 2, ...], ...],
  "traversable": [[0, 0, 1, ...], ...],
  "objects": [
    {"type": "cube", "x": 10.0, "z": 20.0, "scale": 1.0, "rotation": 0.0},
    {"type": "cylinder", "x": 15.0, "z": 25.0, "scale": 1.5, "rotation": 45.0},
    {"type": "pyramid", "x": 20.0, "z": 30.0, "scale": 2.0, "rotation": 90.0}
  ]
}
```

## 3D Объекты
Каждый тип объекта находится в отдельном файле:
- **cube.py** - куб
- **cylinder.py** - цилиндр  
- **pyramid.py** - пирамида

Система должна позволять легко добавлять новые типы объектов в будущем.

## Физика и коллизии
- Простое перемещение по heightmap с учётом высоты terrain
- AABB коллизии с объектами на карте
- Гравитация и прыжки
- Ограничение движения по краям карты

## Архитектура
```
dbh-ww1/
├── main.py          # Точка входа, основной цикл
├── engine.py        # Игровой движок (логика, управление, физика)
├── map.json         # Файл карты
├── objects/         # Директория с объектами
│   ├── __init__.py
│   ├── cube.py
│   ├── cylinder.py
│   └── pyramid.py
└── assets/          # Текстуры и ресурсы (если нужны)
```

## Преимущества Ursina
- Простая установка: `pip install ursina`
- Встроенная поддержка FirstPersonController
- Легкая работа с 3D моделями
- Встроенный редактор (ursina editor)
- Понятный API для создания объектов и карт
